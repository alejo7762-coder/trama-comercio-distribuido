Trama es un prototipo académico de comercio electrónico. Esta versión conecta el catálogo y el registro de productos con una API FastAPI y una base de datos SQL Server configurada para el entorno local.

Explorar catálogoAdministrar productos

Alcance de esta versión

El catálogo permite consultar productos y filtrarlos por nombre o categoría. El módulo administrativo permite registrar productos y revisar el inventario. La autenticación, los pedidos, los pagos y las notificaciones siguen fuera del alcance funcional de esta versión.
