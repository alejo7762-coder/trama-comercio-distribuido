01 · Elementos principales

Seis servicios, una experiencia de compra

Cada bloque del sistema está pensado para operar de forma independiente y escalar por separado, según la carga que reciba.

primer avance

Catálogo

Productos, categorías e inventario. Ya se consulta y se registra desde la interfaz con datos de SQL Server. MongoDB está previsto en el diseño.

diseñado

Usuarios

Registro, autenticación y roles de cliente y administrador.

diseñado

Carrito

Administración del carrito de cada usuario mientras navega el catálogo.

diseñado

Pedidos

Registro, confirmación y consulta del estado del pedido, coordinado con el patrón Saga.

diseñado

Pagos

Procesamiento con control transaccional ACID en SQL Server, evitando cobros duplicados.

diseñado

Notificaciones

Confirmaciones de compra y cambios de estado, entregados de forma asíncrona.
